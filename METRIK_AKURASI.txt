WARAS AI - LAPORAN METRIK AKURASI
=================================
Wawasan Analisis Raga dan Sikap: koreksi postur squat real-time dari kamera.
Metode: Yao et al. (2026), Non-Standard Squat Posture Detection Method Using
Human Skeleton, Computers 15(5):293, doi:10.3390/computers15050293.
Sumber angka: colab/waras_fit.ipynb, dijalankan dengan seluruh data Zenodo.


1. DATASET
----------
Sumber          : data skeleton MediaPipe dari Zenodo (lampiran paper)
Jumlah subjek   : 17 orang
Jumlah klip     : 226 klip, 1 klip = 1 repetisi squat
  - Standar       : 193 klip
  - Shallow       :  23 klip (kurang dalam)
  - Good morning  :  10 klip (badan terlalu membungkuk)
Jumlah frame    : 18.302 frame (15.470 frame squat standar dipakai untuk regresi)


2. CARA KERJA MODEL
-------------------
Model ini bukan deep learning, melainkan aturan berbasis regresi linear:
  a. Sudut panggul dan lutut dihitung dari titik bahu, panggul, lutut, dan
     pergelangan kaki dengan hukum cosinus.
  b. Cek koordinasi : sudut_panggul ~ k x sudut_lutut + b
                      Minimal 90% frame harus berada dalam toleransi +/- tol derajat.
  c. Cek kedalaman  : di titik terendah, panggul tidak boleh lebih tinggi dari
                      lutut lebih dari delta x panjang paha.

Parameter final (lib/waras_params.json):
  k            = 0,9549
  b            = 0,0923
  tol          = 14,28 derajat
  delta        = 0,033
  minPassRatio = 0,90


3. METODE VALIDASI
------------------
Leave-One-Subject-Out (LOSO) cross-validation:
setiap subjek diuji memakai parameter yang di-fit TANPA data subjek tersebut,
lalu diulang untuk ke-17 subjek. Dengan cara ini, model selalu diuji pada orang
yang belum pernah ia lihat.

LAMPIRAN: RUMUS
---------------
  y = sudut panggul aktual, y^ = k*x + b (prediksi), n = jumlah frame

  MAE   = (1/n) * SUM |y - y^|
  MSE   = (1/n) * SUM (y - y^)^2
  RMSE  = sqrt(MSE)
  R^2   = 1 - SUM (y - y^)^2 / SUM (y - mean(y))^2
  MAPE  = (100%/n) * SUM |y - y^| / y
  RAE   = SUM |y - y^| / SUM |y - mean(y)|
  RRSE  = sqrt( SUM (y - y^)^2 / SUM (y - mean(y))^2 )

  Akurasi     = (TP + TN) / (TP + TN + FP + FN)
  Precision   = TP / (TP + FP)
  Recall      = TP / (TP + FN)
  Specificity = TN / (TN + FP)
  F1          = 2 * Precision * Recall / (Precision + Recall)
